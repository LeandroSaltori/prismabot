# 1. Preparar ambiente

### [Link para aula completa - portal do assinante](https://prismatelecomservicos.com/ rel=)

Nesta aula, vamos cobrir os dois pré-requisitos fundamentais que você precisa preparar antes de instalar o Prismabot: a contratação de um servidor (servidor) e a configuração de um domínio.

#### ⚠️ [Requisitos](/diretrizes-e-politicas/pre-requisitos-de-instalacao-e-utilizacao)

1- servidor

* 4 vcpus
* 16 gb de RAM
* Latência até 50 ms
* SSD ou NVME à partir de 200gb
* Ubuntu 20.04, 22.04 ou 24.04 LTS sem Painel
* Arquitetura AMD

#### Passo a passo do vídeo

### Passo 1: Contratação do Servidor (servidor)

A primeira etapa é ter um servidor na nuvem.

* **Ação:** Contrate um plano de servidor. Recomendamos o uso do sistema operacional **Ubuntu 20.04, 22.04 ou 24.04 LTS sem Painel**.
* **Localização:** Dê preferência a um servidor localizado no Brasil para garantir baixa latência.
* **Ao Final:** Após a contratação, o provedor irá fornecer um **endereço de IP** para nuvem. Guarde este número.

### Passo 2: Configuração do Domínio

O Prismabot utiliza dois subdomínios: um para a interface (front-end) e outro para a API (back-end).

* **Ação:** Acesse a zona de DNS do seu domínio.
* **Crie dois Apontamentos do Tipo “A”:**

  1. **Front-end:** Crie um subdomínio (ex: `app`) apontando para o **IP da nuvem**.
  2. **Back-end:** Crie outro subdomínio (ex: `api`) apontando para o **mesmo IP da nuvem**.
* **Aviso para Cloudflare:** Se você usa o Cloudflare, lembre-se de desativar o proxy (clicar na “nuvem laranja” para deixá-la cinza).

### Passo 3: Verificação da Propagação (DNS Checker)

Após criar os apontamentos, é preciso aguardar a propagação.

* **Ação:** Use uma ferramenta online como o **DNS Checker** <https://dnschecker.org/>
  para verificar seus dois subdomínios. O processo está concluído quando a maioria dos locais exibir o IP correto.

### Encerramento

Com a servidor contratada e os domínios apontados, seu ambiente está pronto! Na próxima aula, vamos conectar ao servidor e rodar o instalador.
